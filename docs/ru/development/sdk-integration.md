# Интеграция SDK и touch/UI

На 12 ноября 2026 года рабочие деревья `Flint-IgniteSDK/` и `FlinT-OS/platform/` содержат согласованные незакоммиченные изменения touch/UI (`ContractRevision=0x20261112`). OS собирается с локальным `platform/` без внешнего override. Указатель подмодуля по-прежнему `594eae4631f4fc5242a9c828bb7e3523e9758149`; сам этот коммит не содержит новых контрактов.

```sh
idf.py -B build/sdk-integration -DSDKCONFIG=config/sdkconfig -DIDF_TARGET=esp32s3 build
```

Генерация принадлежит SDK: `cmake/FlintGenerate.cmake` создаёт реестры и пакеты в `<build>/generated/sdk/`. OS использует сгенерированные заголовки перед исходными и формирует `factory.bin` из этих же системных пакетов. Примеры при сборке прошивки пропускаются; исходники SDK не перезаписываются. Подробности: [руководство SDK](../../../platform/docs/ru/SDK.md#генерация-без-изменения-исходников).

Для воспроизведения на другом ПК нужно перенести рабочие SDK-правки целиком. После разрешённого коммита и публикации SDK потребуется намеренно обновить pin OS; без этого чистый clone получит прежний SDK. В этой работе коммиты и смена pin не выполнялись.

Форматы пакетов, протокол и таблица разделов не менялись в рамках устранения генерации. Новые touch/UI-контракты уже присутствовали в исходных незакоммиченных правках. Application-only OTA не обновляет заводские пакеты: прошивка и `factory.bin` должны происходить из одного дерева SDK.
