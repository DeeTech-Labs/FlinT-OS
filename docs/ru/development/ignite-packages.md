# Пакеты Ignite

Ignite — универсальный бинарный формат приложений, циферблатов, тем, локалей, ресурсов и виджетов. Заводские и пользовательские компоненты используют общий валидатор и Runtime.

## Сборка пакета

Из корня репозитория:

```bash
python3 -m pip install Pillow
python3 platform/tools/compile_ignite.py \
    platform/examples/pc-monitor/project.json build/pc-monitor.ignit
```

Проект объявляет ID, издателя, секции компонентов, лимиты памяти и области разрешений. Интерфейс, ресурсы и манифест компилируются на компьютере. Flare устанавливает новые пакеты без изменения исходников прошивки.

## Установка и обновление

Flare передаёт возобновляемые бинарные блоки, проверяет хеш полного файла и промежуточный пакет, затем атомарно фиксирует реестр. Предыдущая версия сохраняется для отката. Фиксированных слотов установки нет. Пользовательский пакет не может заменить защищённую заводскую идентичность или унаследовать расширенное разрешение после обновления.

## Исполнение и ограничения

Декларативные экраны поддерживают общие шрифты, атласы глифов пакета, изображения, локализованный текст и разрешённые привязки данных. Язык приложений — Lua. Ограниченный Runtime работает в SDK, симуляторе и firmware Spark; текущий контракт требует отдельной повторной аппаратной приёмки. Службы используют отдельные VM и явный execute grant, продолжают работу после закрытия UI; model admission и hardware acceptance описаны в sensor-service. [Контракт платформы](../../../platform/README.md) определяет форматы, безопасность и лимиты ресурсов.
