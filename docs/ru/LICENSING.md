## Область лицензий

Собственный код и техническая документация: PolyForm Noncommercial 1.0.0 (неизменённый текст в `LICENSE`). Для собственного кода OS действует отдельное разрешение сообществу. Подмодуль `platform/` имеет собственную смешанную лицензию IgniteSDK; его условия нельзя заменять лицензией родительского проекта. Разрешение на разработку независимых Ignite позволяет использовать необходимые средства SDK и Flare для платных приложений.

Сторонние библиотеки, Lua (MIT), LovyanGFX, Qt и шрифты Lato (OFL-1.1) сохраняют собственные лицензии и уведомления; см. [NOTICE](../../NOTICE) и лицензионные файлы зависимостей. Наличие имени в истории Git не подтверждает передачу авторских прав. По текущей истории во всех четырёх репозиториях указан один автор deexsed; это не доказательство отсутствия сторонних прав.

Юридические тексты PolyForm и Apache сохраняются без перевода как лицензионные оригиналы. Собственные дополнительные разрешения имеют каноническую русскую редакцию; английские тексты — переводы. Отдельная документация о лицензировании распространяется под Apache-2.0, кроме самих юридических разрешений и исходных текстов лицензий.

## Язык и обновления

Русский — канонический язык сопровождаемой документации. Основной README в корне — на русском; самостоятельный английский перевод находится в `docs/en/README.md`. Тематические оригиналы находятся в `docs/ru`, переводы — в `docs/en` с теми же именами. При изменении поведения сначала обновляется русский оригинал, затем перевод. При расхождении собственных текстов приоритет у русского; это не изменяет оригинальные лицензии третьих лиц.

Исторические `CHANGELOG.md`, снимки журналов сайта, исходные сторонние документы и тексты стандартных лицензий сохраняют исходный язык; они не задают текущую политику. Язык строк интерфейса и ключей API не меняется.
