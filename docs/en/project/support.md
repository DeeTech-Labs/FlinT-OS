# Support

| Need | Where |
|------|--------|
| Bug | [Issues](https://github.com/DeeTech-Labs/FlinT-OS/issues) — Bug report |
| Feature | Issues — Feature request |
| New face | Issues — Face proposal |
| Questions / ideas | [Discussions](https://github.com/DeeTech-Labs/FlinT-OS/discussions) |
| Security | [SECURITY.md](security.md) — not a public issue |

Include board profile (FlinT Spark / `flint_spark` or custom), FlinT OS commit or version, ESP-IDF version, and serial logs (redact secrets).

Docs live under [`docs/`](../..) (see the Docs section in [README.md](../../../README.md)). Code of Conduct: [CODE_OF_CONDUCT.md](code-of-conduct.md). There is no project Wiki.

## Documentation and contribution terms

Russian is canonical; update Russian documentation and its English translation together. Authors retain copyright. Contributions use the applicable component license; they do not imply assignment or unrestricted commercial relicensing. See [licensing scope](../legal/licensing.md).

Before filing an issue use the [symptom checklist](../getting-started/device-use.md). Host/simulator tests do not establish physical hardware behavior.
