# Пользование устройством и восстановление

[Оглавление](../README.md) · [English](../../en/getting-started/device-use.md) · [Flare: пошаговое руководство](https://github.com/DeeTech-Labs/Flint-Flare/blob/main/docs/ru/USER-GUIDE.md)

## Перед первым подключением

Это development firmware, не инструкция для произвольных ESP32-часов. Активный профиль
`flint_spark` описывает Super Mini с ST7789. В нём нет touch/buttons/battery/sensors;
не ожидайте экранного ввода, заряда или температуры от display-only платы. Управляйте
ею через Flare. `device.future.toml` для Waveshare неактивен и физически не подтверждён.
Не копируйте его поверх активного конфига без проверки электрической ревизии, памяти и GPIO.

Если устройство уже прошито совместимым OS, прошивать его для установки Ignite не нужно.
Подключите data-USB, выберите порт и USB во Flare. Совместимый handshake показывает устройство;
несовместимость требует согласованных firmware/factory/Flare/SDK, не стирания данных.
BLE первый раз привязывается с подтверждением через доверенный USB; шаги — в руководстве Flare.

## Приложения, часы и доступ

В Ignite Hub установите `.ignit`, дождитесь подтверждения, выберите компонент и запустите.
Часы/тема/язык выбираются как роли; это не изменение прошивки. Factory packages защищены.
Перед выдачей permission проверьте пакет и требуемые данные: declaration — запрос,
а не разрешение. Отзыв прекращает новые readings/events; уже переданные значения
и намеренно сохранённые приложением данные не исчезают задним числом.

UI и service запускаются отдельно. Закрытие UI или Flare не останавливает разрешённую
службу устройства. В Diagnostics Flare можно Start/Stop/Pause/Resume, отозвать execution
и независимо разрешить/включить autostart. Autostart выключен по умолчанию, требует двух
grants и явной политики; обновление пакета не выдаёт новые права автоматически.
На конфигурации с проверенным физическим вводом factory Services доступен из Apps для
локальной остановки/отзыва. **На активном display-only Spark такой ввод не сконфигурирован**:
не рассчитывайте на локальные кнопки; используйте совместимый Flare/USB.

## Настройки и показания

Синхронизация времени и UTC offset доступны в настройках часов Flare. Сначала дождитесь
подтверждения; отдельная ошибка RTC означает частичный результат, а не отмену времени Core.
Brightness/авторежим/mute работают только с настроенными backend. Активный профиль не
даёт эти аппаратные функции автоматически. Без подтверждённой battery model показывается
напряжение, не SOC/charging/ETA. Diagnostic sampling включается явно, имеет lease и
прекращается при закрытии панели/disconnect; это не grants приложения.

## Если что-то не работает

| Симптом | Проверка по порядку |
| --- | --- |
| Порт не найден | data-кабель → питание → порт ОС → закрыть terminal/monitor, занявший USB → выбрать порт во Flare |
| Несовместимая сборка | сверить contract revision firmware/factory/Flare/package → пересобрать согласованным SDK; не erase_flash |
| `not_supported` / «not supported» | проверить активную модель и наличие backend; запрос не включает отсутствующий модуль |
| `source_unavailable` | источник настроен, но отсутствует/ошибается/stale; проверить state/reason и аппаратное подключение с разработчиком |
| `permission_denied` | declaration именно component → подтверждённый grant → текущая package generation |
| pending / not_ready | дождаться deadline/инициализации и перечитать status; нулевые значения не заменяют отсутствие sample |
| Служба не запускается | execute grant → model support → energy policy → resource_exhausted/fault reason; не увеличивать лимиты вслепую |
| BLE выключен | использовать USB для включения; запуск Companion не включает радио автоматически |

При `faulted` устраните причину и явно перезапустите службу. Ошибка quota/OOM не должна
лечиться бесконечными автоповторами. Перевод времени UTC не исправляет sensor deadlines.

## Восстановление и обновление firmware

Если Flare подключается: «Мои часы» → «Настройки часов» → `Restore factory components`
→ подтверждение. Core сбрасывает выбранные роли clock/launcher/settings/theme/locale и
активирует factory theme/locale/clock. Это **не** erase storage, не переустановка factory.bin,
не ремонт повреждённого тома и не команда остановки всех background services. Остановите
службы отдельно, если цель — прекратить их выполнение.

Если Core/factory/storage не запускается, кнопка Flare может быть недоступна. Recovery
дисплей использует встроенные glyphs независимо от runtime framebuffer; отсутствие
дисплея оставляет logger. Зафиксируйте симптом, firmware SHA и подключение; передайте
разработчику по [SUPPORT](../../../SUPPORT.md). Не форматируйте Flash ради диагностики.

Flare не содержит firmware updater. Разработчик использует [ESP-IDF build/flash](building.md)
и matching factory.bin. Application-only OTA не обновляет factory/partition table.
Изменение карты Flash требует отдельного backup/migration/recovery плана; актуальная
интеграция датчиков/служб не меняла partitions. Не выполняйте erase_flash для обычного update.
Аппаратный reset/BOOT определяется проверенной схемой платы; GPIO future-ревизии не инструкция.
